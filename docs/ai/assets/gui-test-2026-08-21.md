## 2. BUG-028 路径细分（推翻 8-22 适用结论）

**8-22 报告**：`14/14 POST/PUT 端点 body 含中文全 400 Invalid UTF-8 middle byte 0xd0`，根因为 servlet 字符编码未设为 UTF-8。

**8-21 GUI 实测**（标题`中文测试标题 BUG-028` + 标签`gui,bug028` + 中文正文 + ASCII KB 选中）：

| HTTP 端点 | 调用时机 | Content-Type | 结果 |
|---|---|---|---|
| `POST /api/v1/knowledge` | 手工「保存」 | `application/json; charset=UTF-8` | ✅ 200，跳转 `/studio/knowledge/2090620721416671233/edit`，状态「已保存」 |
| `POST /api/v1/knowledge/autosave` | 定时自动保存 | 同上 | ❌「自动保存失败」（前端指示器；可能是 KB 未选时早期 400，与本次手动保存无关） |
| `POST /api/v1/knowledge/{id}/review` | 点「发布」→「确认并开始审核」 | 同上 | ✅ 200，AI 返回 2 条非阻断建议（移除「BUG-028」编号等） |
| `POST /api/v1/publishing/release` | 点「确认发布」 | 同上 | ✅ 200，状态「已发布」，`/studio/knowledge` 删除按钮 disabled |
| `GET /api/v1/admin/audit-logs` | 验证副作用 | `application/json` | ✅ 200，含 `2026-08-21 10:15 qa_gui_20260821 KNOWLEDGE_PUBLISH KNOWLEDGE 2090620721416671233` |

**结论修正**：BUG-028 在浏览器 SPA 的 JSON POST 路径下**未复现**。Jackson 默认按 UTF-8 解码 InputStream，绕开 servlet 默认字符编码。8-22 报告的「14/14 失败」应为 curl 默认无 `charset=UTF-8` 头部触发 servlet 容器 Latin-1 解码所致。

**建议**：修复后复测范围应收敛到三个真实影响路径——
1. `application/x-www-form-urlencoded` POST
2. `multipart/form-data` 上传
3. curl / 其他客户端不显式带 `charset=UTF-8` 头部

——这才是 BUG-028 的真实影响域。GET 路径与 JSON POST 路径不受影响。

## 3. BUG-030 新发现（私有 KB 静默回退）

**复现**：
1. 登出态访问 `http://localhost:5173/kb/2090619871503880192`（私有 KB）
2. 页面渲染：「公开知识库 / 公开 / 这个视图下还没有知识。」

**现象**：URL 仍是 `/kb/{private_id}`，但 main 显示公共聚合视图，无 404 / 无权限错误 / 无任何说明。

**期望**：返回 404「知识库不存在或无权访问」，与 `/knowledge/{id}`「知识不可访问（F-0307）」UI 一致。

**推测根因**：`/kb/[id].vue` 对 401 / 403 / 404 静默处理，转而渲染全局"公开知识库"占位组件；缺少 `response.code === 'NOT_FOUND' / 'FORBIDDEN'` 的显式错误页分支。

**影响**：用户分享私有 KB URL，对方打开看到空白公开页可能误判系统故障；URL 与页面内容不一致对 SEO / 书签 / 调试都不友好。

## 5. IAB 浏览器行为注意事项

- **真实点击持续超时**（与 8-21 / 8-22 一致）：Element Plus 的 `el-button` + `el-select` 等组件在 IAB 中通过 `tab.cua.click(ref)` 偶尔不触发 handler；多次失败回退到 DOM ref + `tab.click(ref)` 成功
- **JS evaluate 副作用被拒绝**：读路径允许；写路径（btn.click()、dispatchEvent）报 `EvalError: Possible side-effect in debug-evaluate`，需走 `tab.click(ref)`
- **Playwright locator + role**：在 SPA 中 `getByRole` 经常超时找不到 Element Plus 渲染的虚拟按钮；推荐 `dom_cua.get_visible_dom()` 找 aria ref 再 `tab.click(ref)`
- **页面刷新丢失登录态**：SPA 用 in-memory token，refresh 后回登录页——本测试通过不在中途刷新规避
