- 日期：2026-08-21（GUI 测试观察）；2026-08-22 登记
- 模块：前端 blog（KnowledgeListPage / ReleasePage）+ 后端 publishing（F-0906）
- 状态：待用户决策（补齐流程 or 文档标注 V2）
- 证据：
  - `KnowledgeListPage.vue:3` 注释：*「删除仅构思/草稿可用（已发布需先下架）」* + 测试实测已发布行「删除」按钮 disabled

  - 路由 `/studio/review` 重定向到 release-list（审核中心 B12 隐藏），无隐藏下架入口
  - 契约面：PRODUCT §4 状态机「已发布 → 已下架（校验版本后可回滚重新发布）」是 MVP 行为基线（§6），但功能总表 F-0906 标注 V2——**自身矛盾**

- 建议：MVP 补下架动作（列表/发布管理页），或明确在 UI 与文档标注「下架 V2」并在删除按钮加引导文案，不得静默置灰
