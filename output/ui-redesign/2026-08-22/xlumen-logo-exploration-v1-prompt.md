# xLumen Logo 方向探索提示词

```text
为中文多用户 AI 知识平台“xLumen”设计四个原创、可投入产品使用的 Logo 方向，制作成一张 16:9 的四象限透明背景方向板，分别标记 A、B、C、D。

品牌含义：x 表示连接、交汇与扩展，Lumen 表示光与清晰；产品用于创建、组织、发布、发现、阅读和持续更新知识。品牌气质应清晰、理性、现代、可信、安静但有识别度。

A：Lumen X。两块精确光面交叉形成强烈的小写 x，中间使用小型负空间光隙。
B：Connected X。四个模块向中心汇聚但不接触，在开放中心周围形成 x，表达多个知识库相互连接。
C：xL Monogram。通过共享笔画和负空间，把小写 x 与大写 L 合并成紧凑字母组合。
D：Open Lumen。两块错位括号形光面同时形成抽象 x 和开放光门，结构最简洁、建筑感最强。

每个象限必须展示：大尺寸图标、准确字标“xLumen”（小写 x、大写 L）、24px 导航尺寸图标测试、纯黑单色轮廓测试。四个方向大小和视觉权重一致。

颜色：#5367E8 为主色，#12A594 只能作为一个很小的辅助色面或点；同时必须支持纯黑单色。扁平矢量风格、强轮廓、平衡负空间、边缘清晰。

禁止渐变、阴影、3D、纹理、样机、吉祥物、星形、书本、灯泡、大脑、聊天气泡、无限符号、通用六边形、水印和额外宣传语。
```
