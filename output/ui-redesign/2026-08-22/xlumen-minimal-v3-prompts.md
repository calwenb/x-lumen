# xLumen 简洁版 UI 图片提示词

## 统一视觉基底

```text
为中文多用户 AI 知识平台 xLumen 设计高保真桌面端 Web UI。产品核心是创建、组织、发布、发现、阅读和持续更新知识；知识库、目录和知识内容是视觉主角，AI小光只是辅助入口。

整体气质：简洁、大方、克制、成熟、内容优先。通过留白、文字层级、对齐与细分割线建立品质感，不使用实体书隐喻、装订线、彩色书签、证据轨道、引用连线、插画、纹理、大渐变、玻璃拟态或卡片堆叠。

颜色：页面 #F7F8FA，表面 #FFFFFF，主文字 #182230，次文字 #667085，主色 #5367E8，AI小光 #12A594，边框 #E7EAF0。靛蓝是唯一主色，青绿色只用于 AI小光。

字体：统一使用现代中文无衬线字体，类似 Inter + 苹方/思源黑体；只使用 4 个字号、3 个字重。代码块使用 JetBrains Mono。正文对比度符合 WCAG 2.2 AA。

约束：真实可实现的 Vue 3 + Element Plus 产品界面；中文清晰；不增加未定义的产品功能；产品内 AI 统一命名为“AI小光”；无水印。
```

## 品牌视觉方向

```text
使用上述统一视觉基底，为 xLumen 生成一张 16:9、2560×1440 风格的极简品牌与 UI 方向板。使用精确的 12 栏网格和大量留白，只保留四个区域：左上角 xLumen 字标与品牌语句、精简色板、单字体排版层级、占据下半部分的真实 UI 系统预览。

Logo 使用现代几何无衬线字标“xLumen”，搭配由两块错位竖直光面组成的扁平靛蓝小图形，不使用 3D。主要文字必须准确出现：“xLumen”“知识，清晰可见”“内容优先”“简洁”“可信”“持续更新”“知识”“知识库”“创作中心”“AI小光”“全部知识”“AI 摘要”。

UI 预览包含扁平顶栏、搜索框、一个主按钮、无卡片容器的知识列表行、干净的文章标题和一条克制的 AI 摘要。列表只用细分割线，不用阴影和嵌套卡片。
```

## 博客首页

```text
使用上述统一视觉基底，生成 xLumen 博客首页高保真桌面截图，16:9 横向，无浏览器外框。这是实际知识列表页，不是营销落地页。

结构：60px 固定顶栏；约 1240px 主内容区；220px 左侧固定筛选栏；820px 单列知识流；剩余空间保持留白，不增加第三栏。

顶栏文字必须准确出现：“xLumen”“知识”“知识库”“创作中心”“AI小光”“搜索知识/知识库…”“写知识”；头像仅用字母 C。

左栏扁平无卡片，显示：“全部可见知识”“知识库”“技术周刊”“AI 工程笔记”“产品与设计”“目录”“架构实践”“检索与 RAG”“标签”“Vue”“Java”“AI”。当前项只使用浅靛蓝背景和 2px 左侧主色线。

主栏标题：“全部知识”；说明：“更新时间倒序 · 共 24 篇”。展示四条无卡片知识行，以 #E7EAF0 细线分隔。标题依次为：“多模型路由：从策略到可观测性”“RAG 引用链路的设计与验证”“把知识库做成可持续更新的系统”“Vue 组合式函数的边界设计”。每行显示知识库、目录、两行摘要、作者 Calwen、日期、阅读时间、阅读量和 3 个中性标签。仅第二行显示一个很小的青绿色文字标签“AI 摘要”。

不要营销 Hero、卡片墙、彩色侧签、右侧信息图、阴影列表、衬线标题、渐变或装饰插画。
```

## 知识展示页

```text
使用上述统一视觉基底，生成 xLumen 知识详情页高保真桌面截图，16:9 横向，无浏览器外框。文章阅读是唯一视觉主角。

结构：60px 固定顶栏；约 1120px 阅读区；190px 左侧固定目录；760px 正文；没有右侧内容面板。正文不放在卡片中，不使用边框和阴影。

顶栏显示：“xLumen”“知识”“知识库”“创作中心”“AI小光”“搜索知识/知识库…”“写知识”。文章路径：“AI 工程笔记 / 检索与 RAG”；标题：“RAG 引用链路的设计与验证”；元信息：“Calwen · 发布于 2026-08-18 · 更新于 2026-08-20 · 12 分钟阅读 · 1,284 阅读”；标签：“RAG”“知识库”“系统设计”。

左侧目录显示：“目录”“为什么需要引用链路”“检索与权限边界”“生成与内容绑定”“验证与回归”。当前项只使用靛蓝文字和 2px 左侧线。

标题下方放一条扁平 AI 摘要：浅中性底、2px 青绿色左线、无边框、无卡片圆角。文字：“AI 摘要”“本文梳理检索、生成与内容引用之间的关键设计，并给出可验证的实现路径。”

正文使用 16px 中文无衬线字体、1.85 行高，包含 H2“生成与内容绑定”、数段正文、一个 2px 靛蓝左线引用块和一个深色代码块。操作区为单行：“问「小光」”“点赞”“收藏”“纠错反馈”；底部显示“评论 12”。不要浮动工具栏、证据侧栏、引用连线、文章卡片、渐变或装饰图形。
```
