# xLumen 博客首页 V4 图片编辑提示词

```text
请以现有 xLumen 极简博客首页图片作为唯一编辑底图，保留原图的 16:9 构图、顶栏、左侧栏宽度、主内容宽度、全部文字内容、四条知识顺序、留白、无衬线字体和细分割线，只进行以下修改：

1. 在 xLumen 文字左侧增加一个约 26×26px 的扁平几何 Logo：由两块错位光面形成字母 X，主色 #5367E8，只有一个很小的 #12A594 点缀；不要 3D 和大渐变。
2. 在顶栏“AI小光”右侧增加一个青绿色四角星矢量图标；在第二条知识的“AI 摘要”左侧使用同款小星。星形是统一图标，不使用 emoji。
3. 将左侧纵向排列的 Vue、Java、AI 改成“标签云”：使用自动换行的小型胶囊标签，显示 Vue、Java、AI、RAG、前端、后端、系统设计、知识库；标签高度一致，根据文字长度决定宽度，使用非常浅的靛蓝、青绿、天蓝和琥珀底色，正文保持深色。
4. 在四条知识的 Calwen 前增加统一的 24px 圆形发布者头像：靛蓝圆形、白色字母 C，不虚构真人照片；日期、阅读时间、阅读量保持原样并对齐。
5. 增加克制的语义配色：靛蓝 #5367E8 只用于 Logo、当前导航、主按钮与焦点；青绿 #12A594 只用于 AI小光和 AI 摘要；浅天蓝与浅琥珀只用于知识库标识和部分标签背景。技术周刊使用蓝色小圆点，AI 工程笔记使用青绿色小圆点，产品与设计使用琥珀色小圆点。知识标题、摘要、元数据和分隔线继续使用中性色，确保阅读舒适。

不要改变布局，不要增加第三栏、营销文案、卡片容器、列表阴影、证据轨道、玻璃拟态、装饰插画或大面积彩色背景；不要改名 AI小光；中文必须清晰；不要水印。
```
